# React Native CLI  
### Native Applications for iOS and Android

---

## 📖 Description

**React Native: Native Applications for iOS and Android**

This complete **React Native** course is designed to teach you the framework in a **solid and robust way**, with more than **42 hours of video content** (not including tasks and exercises).

A basic understanding of **React with Hooks** is strongly recommended. The goal of this course is to help you **transfer your existing React knowledge** into building real, production-ready **mobile applications** using React Native.

The course is based on **React Native CLI (not Expo)** and uses **TypeScript** from start to finish. While TypeScript is not mandatory in React Native, **everything in this course is built with it** to demonstrate the power of strict typing and how it helps automatically generate documentation for functions and methods.

---

## ⚠️ Important Notice

React Native officially recommends using a framework like **Expo** to develop applications with this technology.

If your goal is to **learn React Native from scratch**, we highly recommend taking the **React Native with Expo** course first.

This course uses **React Native CLI**, which is intended for developers who specifically need to learn React Native **in its purest form**, with direct access to native code and configurations.

## 🧠 What You Will Learn

Throughout the course, we will cover most of the existing React Native components. We’ll start with a **Hello World**, then move on to animations, state management, native resources, and gradually increase complexity until we reach **deployment to the Google Play Store and Apple App Store**.
